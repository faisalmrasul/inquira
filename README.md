# 🛡️ Inquira — The Trust Layer for Professional AI
<img width="1350" height="598" alt="Inquira" src="https://github.com/user-attachments/assets/ad3148fc-4e55-41bc-b495-041c780f3ebc" />

Inquira is a Streamlit prototype that evaluates every AI query against the
**EU AI Act (Regulation (EU) 2024/1689)** as a universal design standard.
Four workspaces — Professionals, Business Owners, Students, Teachers — each
present a single Google-style prompt bar with file attachment. Every query is
evaluated for responsible AI use **before** any output is returned, and results
are rendered through two explicit lenses:

- **Policy angle** — is this use lawful under the EU AI Act?
- **Governance angle** — did the organisation operate its controls correctly?

A dedicated RAI Governance dashboard adds a status banner, a 4-pillar checklist,
remediation actions, and an exportable compliance certificate.

> **Prototype** — designed against Regulation (EU) 2024/1689 as a universal
> design standard. Not CE-marked. Not placed on the EU market.

---

## ✨ Features

- **Four workspaces** with risk-tier registration (Annex III aware).
- **Art. 5 Prohibited Practice Shield** — regex-based pre-execution blocking.
- **Human oversight gate** (Art. 14) — named approver required for HIGH risk.
- **Transparency / AI disclosure** (Art. 13, 50) on every allowed output.
- **Hash-chained ledger** (Art. 12, 19) — tamper-evident compliance events.
- **Policy vs Governance angles** side by side.
- **RAI Governance dashboard** — traffic-light status, 4 pillars, why-flagged.
- **Auto-Fix** — generates an EU-compliant output variant.
- **Compliance certificate** — exportable JSON audit report.
